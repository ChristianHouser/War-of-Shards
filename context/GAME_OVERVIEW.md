# Game Overview

**Working Title**: [Name TBD]  
**Theme**: Fantasy

**Genre**: Match-3 Tactical RPG (mobile-first)

**Core Fantasy**: Collect and grow fantasy heroes. Match gems to fuel them, then command them in positional battlefield combat against enemy forces.

**High-level Loop**:
1. Match gems on the bottom board → fill each hero’s individual mana/stamina bar.
2. Spend mana/stamina on the upper battlefield to attack, use abilities, or act.
3. Defeat the enemy team (a ranged unit is protected from melee only while a melee unit guards its specific lane — see context/GAME_MECHANICS.md).
4. Earn rewards → strengthen heroes → unlock new abilities → progress the campaign / compete in PvP.

**Team Size**: Maximum 6v6 at the campaign/meta level. Missions can be uneven (e.g. 4v6, 5v3, etc.). The current battlefield prototype screen caps each side at 5 characters total (`TEAM_CAP = 5`), any mix of Melee and Ranged.

**Key Modes**:
- Main Campaign
- Hero Collection & Progression
- PvP
- Side Missions (individual hero backstories)

**Platform Goal**: Runs smoothly on most phones and tablets (similar accessibility target to Empires & Puzzles).

**Unique Selling Points**:
- True positional combat (melee front line protects ranged back line per-lane, with staggerable half-step coverage)
- Match-3 is pure resource generation only
- Per-hero mana/stamina bars
- Optional auto-play for the battlefield layer
- Heroes unlock higher-cost abilities while keeping cheap basic attacks
